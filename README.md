# ☕ Cafeteria do Nexus

Projeto acadêmico de desenvolvimento web que simula o site de uma cafeteria, apresentando um catálogo de produtos e uma proposta de gerenciamento de pedidos.

⭐ Como professor, fiz esse projeto desenvolvido para fins acadêmicos e de aprendizado em desenvolvimento web.

## 📌 Sobre o projeto

A **Cafeteria do Nexus** é uma aplicação web desenvolvida com o objetivo de praticar conceitos fundamentais de desenvolvimento Front-end, utilizando HTML, CSS e JavaScript.

O projeto apresenta uma interface para uma cafeteria fictícia, permitindo visualizar bebidas e comidas disponíveis, seus preços e informações.

Também conta com uma implementação JavaScript para gerenciamento de pedidos, incluindo cadastro de clientes, seleção de bebidas e controle da fila de pedidos.

## 🚀 Funcionalidades

- Exibição de catálogo de bebidas e comidas.
- Apresentação de imagens, descrições e preços dos produtos.
- Interface visual personalizada para a cafeteria.
- Cadastro de pedidos com nome do cliente.
- Seleção de bebidas.
- Campo para observações personalizadas.
- Atualização automática da quantidade de pedidos na fila.
- Opção para marcar pedidos como prontos e removê-los da fila.
- Validação dos campos obrigatórios.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo da página.
- **CSS3:** estilização, cores, layout e responsividade.
- **JavaScript:** manipulação do DOM, eventos, validações e gerenciamento de pedidos.

## 💻 Como executar o projeto

1. Clone este repositório:


git clone https://github.com/nicolassantana0505/Cafeteria-ProjetoAcademico.git


1. Entre na pasta do projeto:


cd Cafeteria-ProjetoAcademico


3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para executar a versão estática do projeto.
